# Aduke Studio Admin Dashboard

A premium admin panel for a unisex salon & spa, built with React, Tailwind CSS v4, Recharts, and Framer Motion.

## Features

- **Live KPIs** - Revenue, Expenses, Net Profit, Bookings, and New Customers with animated counters that fluctuate in real time
- **Dark Mode** - Full dark/light theme with system preference detection and localStorage persistence
- **Interactive Charts** - Revenue trends, bookings by category, busiest hours, and top performing services
- **Booking Management** - Filter by status, view details, confirm or cancel appointments
- **Service Management** - CRUD operations with image upload, bulk status toggle
- **Customer Directory** - Client profiles with booking history
- **Analytics** - Revenue over time, customer retention metrics, top services
- **Settings** - Business profile, staff management, operating hours, notification preferences
- **Notifications** - Real-time bell with unread badges and dropdown
- **Responsive Sidebar** - Collapsible with animated nav and activity feed

## Tech Stack

- React 19 + React Router v7
- Tailwind CSS v4 with @theme custom properties
- Recharts for data visualization
- Framer Motion for animations
- Lucide React for icons
- Vite for build tooling
